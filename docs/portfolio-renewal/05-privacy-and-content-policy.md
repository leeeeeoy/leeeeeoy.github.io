# 개인정보와 콘텐츠 처리 기준

## Git에 저장하지 않는 정보

- 원본 이력서와 추출 텍스트
- 전화번호
- 개인 이메일 주소
- 상세 주소
- 생년월일
- 서명, 증명서, 지원서 식별값
- 지원 기업별 자기소개와 지원 동기
- 공개 승인을 받지 않은 회사 내부 정보
- API Token, Account Secret, OAuth Token

## 저장 가능한 정보

공개 포트폴리오에 노출하기로 한 다음 정보만 저장한다.

- 회사명, 역할, 근무 월 단위 기간
- 공개 가능한 서비스 설명
- 검증된 사용자·다운로드·성능 수치
- 기술적 문제 해결 과정
- 공개 GitHub, 블로그, 서비스 링크

## 디렉터리 규칙

다음 경로는 `.gitignore`로 차단한다.

```text
resume/
docs/private/
docs/**/private/
docs/**/raw/
```

원문 분석이 필요하면 운영체제 임시 디렉터리를 사용하고 작업 종료 후 삭제한다.

## 커밋 전 검사

```bash
git status --short
git diff --cached
git grep -nE '전화|이메일|상세 주소|생년월일' -- docs
```

문자열 검사만으로 모든 개인정보를 찾을 수 없으므로 문서 리뷰를 함께 수행한다.

## 공개 연락 수단

저장소에 이메일을 직접 넣지 않는 선택지는 다음과 같다.

- GitHub 또는 LinkedIn 링크만 제공
- 빌드 환경변수에서 공개 연락 주소 주입
- 별도 contact form 서비스 사용

현재 요구에는 GitHub·LinkedIn 링크만으로 충분하며 contact form은 추가하지 않는다.
