## 범위와 기준

## 실제 검증

- 기존 로컬 Python 3.12 Alpine 이미지에서 외부 네트워크 차단, 빈 허용 환경, 읽기 전용 소스 복사본, scratch 64 MiB, 메모리 128 MiB, CPU 1개·10초, PID 32개, 파일 1 MiB, wall time 30초 제한을 확인한 뒤 하네스만 실행했다. 의존성이나 이미지를 다운로드하지 않았다.
- 문서 15개의 로컬 링크 검사와 자체 테스트 6개가 통과했다. 문서의 인라인 코드 예시를 실제 링크로 읽는 오류는 추가한 테스트가 수정 전 실패하고 수정 후 통과하는 것으로 확인했다.
- 저장소에서 `git diff --check`를 확인했다. 새 CI의 GitHub 실행 결과는 아직 없다.
- Web/API/Go 테스트·빌드, 브라우저·실제 기기, 운영 URL·Cloudflare/GitHub 제어면 검증은 실행하지 않았다. 문서 검사 결과로 이를 대체하지 않는다.

## 보안 점검 결과

Cloudflare `security-audit`의 full workflow를 `quick` profile로 수행한 **부분 소스 감사**다. Web/API/CI·배포 설정과 독립 Lab을 정찰 4역할·탐색 4역할·독립 coverage critic으로 점검했다. 최초 탐색 3회는 사용량 제한으로 결과 없이 실패했고, 재개 후 같은 첫 wave를 완료했다. 완료 역할은 9개, 총 dispatch는 12회다. 다른 모델 계열의 검증이라고 주장하지 않는다.

소스 검토에서 확정할 취약점 후보는 남지 않았다. `findings.json`은 0건이며 이는 운영 안전성 또는 취약점 부재의 증명이 아니다. 현재 호환되는 이전 보안 ledger는 발견하지 못했고, 과거 개인정보 감사 기록을 현재 보안 검증으로 승계하지 않았다.

coverage ledger는 소스 검토 14단위, 현재 의존성 advisory 정보 미확인으로 blocked 1단위, 최종 critic이 찾은 API 자원·비용 경계 deferred 1단위, 명시적 제외 2단위다. quick profile 규칙에 따라 두 번째 탐색 wave는 실행하지 않았다. findings·coverage 검증기는 통과했으며 이는 형식·일관성 검증이다.

전체 ledger·JSON·소스 확인 내역·실행 로그·보고서는 이번 대화의 저장소 밖 작업 산출물로 보존했다. 공개 문서에 로컬 절대 경로·연락처·비밀정보·원본 자료를 복제하지 않는다.

## 개선 우선순위

1. **다음 범위 점검:** 공개 방문 집계의 요청 빈도, 중복 접속에서도 수행하는 D1 batch, 키 증가·만료 정리, 합계 조회 비용과 실제 배포의 제한 정책을 별도 검토한다. 아직 증폭 임계값·공유 피해·운영 정책은 확인하지 않았다.
2. **운영자가 확인할 경계:** 최신 의존성 advisory, 실제 Access/라우트/Secret 범위·CF 헤더 출처·D1 schema, 호스팅 CI의 branch/권한 정책을 현재 상태로 확인한다. 소스 설정의 존재를 적용 증거로 대신하지 않는다.
3. **예방 강화 후보:** CI action의 immutable commit 고정, Web/API 배포 credential 분리·최소 권한, 실제 스크립트 목록에 맞는 CSP 단계적 강화. 현재 경계 위반으로 입증한 취약점은 아니다.
4. **Lab 재사용 전:** 직접 실행 시 listen 주소, 환경 프록시, 공유 사용자·데이터·자원 제한을 명확히 한다. 현재 인증 없는 합성 Lab을 운영 서비스로 취급하지 않는다.

위 보안 개선은 권고이며 이번에 앱 코드나 운영 설정에 적용하지 않았다. 실제 수정은 해당 범위와 회귀 검증을 정한 뒤 진행한다.
