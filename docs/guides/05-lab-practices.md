# Lab — 실험 및 학습 기록 운영 기준

## 목적

Go 등 새로운 기술을 '사용했다'는 결과보다, 의문을 구체화하고 직접 실험해 이론과 비교하는 과정을 기록한다. 모든 실험은 이직용 포장이나 공개 글 발행을 목적으로 할 필요는 없다.

질문과 추가 연구의 선택은 사용자가 맡고, AI는 계획·구현·근거 검토·기록을 보조한다. 사용자가 말하지 않은 경험·생각·이해 정도를 대신 만들어내지 않는다. 이론 학습·코드 분석·공식 문서 검토·비교 연구만으로 질문에 답할 수 있으면 실행 코드를 만들 필요가 없다.

## 가벼운 기본 사이클

**사용자 질문 → 연구 계획·승인 → 필요한 구현/자료 조사 → 근거 분석·Brief → 선택적 이해 대화·후속 후보 → 요청 시 글 초안**

단계별 절차·중단 기준의 원본은 [Lab Workflow](14-engineering-lab-workflow.md)다. 계획·연구 기록은 `labs/<slug>/`에, 읽기 쉬운 글은 `content/lab/`에 둔다. 이미 있는 실험을 새 절차에 맞추기 위해 재측정하거나 당시 계획을 사후에 다시 쓰지 않는다.

연구 깊이와 전달 분량을 분리한다. 핵심 답 → 필요한 원리 → 상세 근거를 선택해서 읽을 수 있게 연결하고, 이해 대화를 시험이나 승인 게이트로 만들지 않는다. 사용자의 학습 성과는 실제 확인된 의견만 기록한다.

- 질문이 충분히 작으면 Markdown 노트만 만든다. 모든 의문을 프로젝트로 만들지 않는다.
- 복잡한 API 서버를 먼저 만들지 않는다. 검증에 필요한 최소 실험 환경부터 시작한다.
- 결과가 예상과 다르면 '실패'로 버리지 말고 조건과 해석을 남긴다.
- 공개 글은 의미 있는 결과가 생겼을 때 `content/lab/`에 선별적으로 작성한다.

## `labs/<slug>/` 최소 요건

```text
labs/go-load-test/
├── README.md       # 목표, 환경, 재현 명령, 테스트 방법
├── (source files)  # 실제 실행 코드
└── results/        # 실행 원본·로그·dump·프로파일: 로컬 보존, Git 제외
```

루트 `.gitignore`는 모든 `labs/**/results/`를 기본 제외한다. 코드·재현 명령·해석·검증 요약은 추적하되 실행 원본·소스 사본·로그·DB dump·프로파일은 로컬에 보존한다. 재실행으로 같은 측정값을 얻는다고 가정하지 않으며 원본을 삭제하지 않는다. 공개 글에 필요한 표·그래프는 사용자 검토 후 콘텐츠 자산으로 별도 선별한다.

민감한 원본은 저장소 밖 안전한 위치에 보존한다. 공개용 데이터가 필요하면 비식별화한 별도 사본에 제거한 필드와 방법·해석 한계를 기록한다. 측정 수치를 예상에 맞춰 보정하지 않는다. 원본 위치와 보존 범위는 명시하고, 로컬 결과 경로를 원격에 존재하는 링크처럼 표시하지 않는다.

## 실험 신뢰성 체크

- 환경: OS, CPU, 메모리, Go 버전, 실행 모드, 서버/클라이언트 같은 호스트 여부
- 측정: 도구 버전, 명령어, 부하 모델(고정 동시성/고정 도착률), warm-up, 측정 시간, 반복 횟수
- 지표: 처리량, latency 분포(p50/p95/p99), 실패 정의, 타임아웃, CPU/메모리
- 비교: 변경 변수는 가능하면 하나만, 제약 조건이 같을 때만 상대 비교
- 해석: 관측 사실과 가능한 원인을 분리. 프로파일링/다른 도구로 교차 검증 권장
- 안전: 공개 외부 시스템에 부하를 발생시키지 않는다. 대상은 소유하거나 명시적 허가받은 로컬/테스트 서버로 제한한다.

## Go Load Lab 첫 실험

**질문:** 동시 요청을 늘리면 Go HTTP 서버 처리량은 계속 증가하는가?

1. 원본이 없어 사용자 승인에 따라 새 표준 라이브러리 CLI/서버를 구현했다. 과거 수치는 사용하지 않았다.
2. `/fast`, `/slow`, `/cpu`에 대해 동일 조건 여러 차례 테스트.
3. 100 → 200 동시성 구간 RPS와 p99 변화를 측정.
4. 서버/클라이언트가 같은 장치에 있으면 병목 위치를 단정하지 않는다.
5. `pprof` 또는 비교용 도구(`hey` 등)와 교차 검증 후 글 작성.

[Phase 4 기록](../archive/work-records/13-phase4-go-lab-record-2026-10-15.md)과 [실험 README](../../labs/go-load-test/README.md)가 현재 실행 근거다. 본 측정 42개와 별도 보조 검증을 보존하고 첫 글은 draft:true로 유지한다.

기존 채팅 스크린샷 숫자는 실험 환경·실행 로그·반복이 확인되지 않는 한 **검증 완료 수치로 고정하지 않는다**.
