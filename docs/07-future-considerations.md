# 향후 검토사항 — 현재 구현 금지

이 문서는 **backlog**이지 현행 요구사항이 아니다. 기능을 미리 만들거나 DB/인증 추상화를 준비하지 않는다.

| 기능 | 재검토 조건 | 고려할 쟁점 |
|---|---|---|
| 댓글 | 실제 글 발행 이후 방문자 의견을 받고 싶을 때 | 스팸, 신고/삭제, 개인정보, 외부 서비스(giscus 등) vs 자체 구성 |
| Google/Kakao/Naver/GitHub 로그인 | 댓글 등 명확한 인증 요구가 있을 때 | 제공자별 OAuth 설정, 운영 정책, 회원 정보 최소 수집 |
| 회원 시스템 | 반복 방문자를 식별해야 하는 기능이 생길 때 | 탈퇴·삭제·세션 관리·보안 사고 대응 |
| 관리자 UI / CMS | Markdown+Git 발행이 실제 병목이 될 때 | 비용·인증·운영 복잡도 |
| 좋아요/알림/구독 | 콘텐츠와 방문자 규모가 의미 있게 생겼을 때 | 개인정보·악용 방지·전송 인프라 |
| SEO/정적 프리렌더/SSG 전환 | 글 상세의 검색 노출 문제가 실제로 확인될 때 | 현재 SPA 대비 비용/단순성/메타데이터 |
| 원격 Lab 데모 서비스 | 공개 실행이 교육적으로 필요할 때 | 보안/비용/악용/권한, 테스트 인프라 분리 |

이번 단계에서 허용되는 건 이 목록에 **의사결정 근거를 추가하는 것**뿐이다. 기능 구현은 사용자 별도 승인 이후 별도 계획으로 진행한다.
